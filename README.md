# ✨ Todo Master - Advanced Task Management App

A modern, feature-rich Todo application built with React, featuring dark/light themes, local storage persistence, and smooth animations. Perfect for managing your daily tasks with style and efficiency!

![Todo Master Demo](https://img.shields.io/badge/Demo-Live-brightgreen) ![React](https://img.shields.io/badge/React-18-blue) ![Vite](https://img.shields.io/badge/Vite-Latest-purple)

## 🌟 Features

### 📝 Core Task Management
- ✅ **Add Tasks** - Create new tasks with optional notes, priority levels, and due dates
- ✏️ **Edit Tasks** - Inline editing with full task modification capabilities
- ❌ **Delete Tasks** - Confirmation-based task deletion to prevent accidents
- ✔️ **Mark Complete/Incomplete** - Toggle task completion status with visual feedback

### 🎨 User Interface & Experience
- 🌙 **Dark/Light Mode Toggle** - Seamless theme switching with preference persistence
- 📱 **Fully Responsive Design** - Optimized for desktop, tablet, and mobile devices
- 🎭 **Smooth Animations** - Framer Motion powered transitions and micro-interactions
- 🎯 **Perfect Centering** - Professional layout with optimal visual hierarchy

### 🔍 Task Organization & Filtering
- 🔍 **Search Functionality** - Real-time search across task titles and notes
- 🗂️ **Filter Tabs** - View All, Active, or Completed tasks with live counters
- 🏷️ **Priority Badges** - Visual priority indicators (High, Medium, Low)
- 📅 **Due Date Management** - Set and track task deadlines with overdue alerts

### 💾 Data Persistence & Management
- 💾 **Local Storage** - All tasks and preferences saved locally
- 🔄 **Auto-Save** - Automatic saving without manual intervention
- 🛡️ **Error Handling** - Graceful handling of corrupted data
- ⚡ **Fast Loading** - Optimized loading with loading states

### 🔔 User Feedback
- 🍞 **Toast Notifications** - Success, info, and error messages
- ⚠️ **Confirmation Dialogs** - Safe deletion with confirmation prompts
- 📊 **Live Counters** - Real-time task count updates
- ⌨️ **Keyboard Shortcuts** - ESC to cancel edit, Enter to submit

### 📌 Advanced Features
- 📝 **Task Notes** - Add detailed descriptions to tasks
- 📅 **Due Date Tracking** - Visual indicators for overdue tasks
- 🏃 **Priority Management** - High, Medium, Low priority classification
- 🎯 **Status Badges** - Clear visual indicators for task status

## 🚀 Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Rakshi2609/to_do_list.git
   cd to_do_list
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to see the app in action!

## 📱 Usage Guide

### Adding a Task
1. Type your task in the main input field
2. Optionally add a note, set priority, and due date
3. Click "Add Task" or press Enter

### Managing Tasks
- **Complete**: Click the checkbox to mark as done
- **Edit**: Click the edit (✏️) button to modify
- **Delete**: Click delete (🗑️) button twice to confirm

### Search & Filter
- Use the search bar to find specific tasks
- Click filter tabs (All/Active/Completed) to view different task states

### Theme Toggle
- Click the theme button (🌙/☀️) in the top-right to switch modes
